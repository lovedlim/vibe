# vibe (준비중)

## 현재 무료 사용가능한 Gemini API
- Gemini 2.5 Flash
- Gemini 2.0 Flash
- Gemini 2.5 Pro, Gemini 3.0 Pro은 엄격한 일일 또는 분당 사용량 제한이 flash보다 커서 추천하지 않음

C:\Program Files\nodejs
