# vibe (준비중)

## 현재 무료 사용가능한 Gemini API
- Gemini 2.5 Flash
- Gemini 2.0 Flash
- Gemini 2.5 Pro, Gemini 3.0 Pro은 엄격한 일일 또는 분당 사용량 제한이 flash보다 커서 추천하지 않음


## 환경 변수 추가 목록 (기본 경로)
- C:\Program Files\nodejs
- C:\Program Files\GitHub CLI

## 명령프롬프트 / 파워쉘 권한 문제
- Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
